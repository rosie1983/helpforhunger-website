# Help for Hunger Website

Static HTML site for helpforhunger.org, hosted on GitHub Pages via the `rosie1983/helpforhunger-website` repo.

## Files
- `index.html` — homepage
- `about.html` — about page
- `contact.html` — contact page
- `get-involved.html` — get involved page
- `help-for-hunger.html` / `help-for-hunger-site.html` — additional pages

## How to publish changes
After editing, commit and push to main:
```
git add -A
git commit -m "describe what changed"
git push
```
GitHub Pages auto-deploys on every push — changes go live in ~1 minute.

## Style notes
- Warm, community-focused tone
- Brand colours: #4a5238 (green), #ff5440 (red/coral), #faf9f5 (cream background)
